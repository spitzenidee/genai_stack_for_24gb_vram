# 03.4 — Failure → Diagnosis → Fix (triage)

Fast triage only. **The full error catalog, "blowing up" playbook, and debug
env vars live in [01.9](../01-phases/01.9-troubleshooting.md)** — go there
after this table points you at the cause. Golden rule: a crash is a *symptom*;
fix the physics, not the algorithm.

## Triage by symptom

| Symptom | Most likely cause | First action → 01.9 section |
|---------|-------------------|------------------------------|
| Crash in the **first few steps** | Steric clash / bad EM / too-large `dt` / topology bug | Re-minimize; reduce `dt`; check topology → **§C/D** |
| Crash **after stable running** | Growing energy term; bad coupled group; box/cutoff under pressure | `gmx energy` — find the spiking term → **§E** |
| **No crash, wrong results** | PBC/fit/index-group error in analysis; wrong ensemble | Re-clean trajectory; check `tcoupl`/`pcoupl` → **01.8 / 01.5** |
| **No output** files | Buffering / NaN / all `nst*`=0 / full disk | `GMX_LOG_BUFFER=0`; check NaN, `nst*`, disk → **§C/F** |
| `grompp` rejects the topology | Charge / order / moleculetype / cutoff-box | → **§B** table |
| `pdb2gmx` fails | Residue/atom-name mismatch, missing atoms | → **§A** table |
| `mdrun` refuses to start: `Update task can not run on the GPU ... not satisfied` | GPU task incompatible (virtual sites, FEP, RE, triangle constraints, ...) | Drop `-update gpu` → `-update cpu` (or `-nb gpu` only) → **01.9 §C / 03.5** |

## Blow-up shortcut (unstable system)

Most constraint/LINCS/1-4/PME crashes are a **blow-up cascade**. Full playbook
in **01.9 §E**. Immediate moves:

1. Set `nstxout-compressed = 1`, re-run from just before the crash, watch which
   atoms go unstable first.
2. Simplify to isolate: single molecule / protein-alone / ligand-in-vacuo.
3. Fix direction: better prep (EM, clashes, topology) **or** smaller `dt`.

## Do NOT

- Increase the cutoff to fix `1-4 (i,j) interaction not within cut-off! r=... Ignored`.
- Paper over warnings with `grompp -maxwarn` — in 2026.3 it **downgrades
  "Unknown left-hand" errors for removed/renamed options to warnings and runs
  with the option's *default* value**, silently producing wrong physics
  (e.g. a renamed soft-core option "works" but the soft-core is off). See
  `01.9` §B.
- Assume the LINCS/SHAKE/PME error is the *cause* — it's the first thing to
  fail when the physics blows up.
- Use old 2026.3 option names (`free-energy-group`, `sc-r`, `lmc-mc-move`,
  `tau-bfric`, `pull-coord`, `umswitch`, `annealing-t`, `qmmm = yes`, ...).
  Look up the current name in `00.5` / `02.xx`.

## Root-cause checklist (details in 01.9 §D)

- [ ] Insufficient EM / steric clashes in the starting structure.
- [ ] `dt` too large for the constraint choice.
- [ ] FEP insertion without soft-core.
- [ ] Pressure/temperature coupling before equilibrium.
- [ ] Position restraints to a too-different reference.
- [ ] Box < 2× cutoff (min-image violation under pressure).
- [ ] Isolated single water molecule.
