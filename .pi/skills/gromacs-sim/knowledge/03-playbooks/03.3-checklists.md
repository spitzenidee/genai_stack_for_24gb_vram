# 03.3 — Per-Phase Checklists

Run these before advancing to the next phase. A failed item = stop and fix.

## Phase 0 — Host / GPU pre-flight (this stack, **run before any grompp/mdrun**)
The RX 7900 XTX has **no VRAM isolation between contexts** — eGPU modes are
mutually exclusive (`llama | comfyui | gromacs | blender`, see the repo
`Makefile` / `scripts/switch-mode.sh`). If another mode is active, its VRAM is
occupied and `mdrun` will OOM/crash on startup — this is a **mode problem,
not a GROMACS problem**.
- [ ] Stack is in **gromacs** mode: `make gromacs` (or `switch-mode.sh
  gromacs`). This stops the other modes' eGPU services and starts
  `gromacs-rocm`.
- [ ] `gromacs-rocm` container is up: `make status` / `docker compose ps`.
- [ ] eGPU VRAM is free: `rocm-smi` (or the gpu-exporter) shows ~no other
  consumer (llamacpp-egpu / comfyui must be down).
- [ ] `gmx --version` inside the container shows HIP + `--offload-arch=gfx1100`.
- [ ] On a **startup** mdrun failure (OOM / device error / segfault before the
  log), suspect the mode/VRAM first — **not** the blow-up playbook in 01.9.

## Phase 1 — Structure prep (`01.1`)
- [ ] Missing residues/atoms modeled or deleted (documented).
- [ ] Alt-loc resolved; crystal water removed (unless studying it).
- [ ] Protonation states set at target pH (His/C-term/N-term).
- [ ] Disulfides present in the curated structure (detected by `pdb2gmx`; no
  `-cys` flag in 2026.3); metals kept+coordinated or deleted.
- [ ] Ligands identified → parameterized (or deleted).
- [ ] Chains contiguous (no non-sequential blocks).
- [ ] `pdb2gmx` ran with the **intended FF + water model** (matched set).

## Phase 2 — Topology/FF (`01.2`)
- [ ] `[ defaults ]` present, first, once.
- [ ] Every `[ molecules ]` name has a `[ moleculetype ]`.
- [ ] `[ molecules ]` order == coordinate-file order.
- [ ] Cumulative charge **integer per residue**.
- [ ] Ligand `.itp` included + added to `[ molecules ]`.
- [ ] Posre file generated and placed in the correct moleculetype.
- [ ] `grompp` parses the topology (test with a minimal MDP).

## Phase 3 — Solvation/ions/box (`01.3`)
- [ ] Box ≥ **2 × cutoff** in all dimensions (with NPT margin).
- [ ] Water model matches the FF.
- [ ] Ions added: net charge ≈ 0 (integer); salt ≈ 0.15 M.
- [ ] No solute–ion clashes; ion counts sensible.
- [ ] Topology `[ molecules ]` updated (SOL/NA/CL) and order-consistent.

## Phase 4 — Energy minimization (`01.4`)
- [ ] `Fmax < emtol` (or machine-precision message with sane `Epot`/`Fmax`).
- [ ] `Epot` in the expected range (~ −10⁵…−10⁶ for solvated).
- [ ] No LINCS/SHAKE warnings in `em.log`.
- [ ] Minimized structure visually sane (no exploded regions).

## Phase 5 — Equilibration (`01.5`)
- [ ] **NVT**: temperature reaches + holds ~300 K; KE stable.
- [ ] **NPT**: pressure → ~1 bar; box volume/density stable.
- [ ] Water density ≈ expected for the model.
- [ ] No constraint warnings; no energy spikes.
- [ ] Solute RMSD stable (restraints working).
- [ ] `refcoord-scaling = com` set (NPT + restraints).
- [ ] (Membrane) `pcoupltype = semiisotropic`; area/thickness relaxing.

## Phase 6 — Production (`01.6`)
- [ ] Position restraints **off** (unless the protocol requires them).
- [ ] `nsteps × dt` = intended total time.
- [ ] Output frequencies sane (xtc ~2 ps; no full-precision every frame).
- [ ] Checkpoint interval set via `mdrun -cpt` in minutes (never lose > ~100 ps; `nstcheckpoint` is obsolete).
- [ ] Energy drift acceptable; T/P stable.
- [ ] No constraint/range-check warnings in the log.
- [ ] (GPU) log confirms GPU offload engaged.

## Phase 7 — Restart/parallelization (`01.7`)
- [ ] Restart uses **checkpoint** (`-cpi`) + same `.tpr` (exact restart).
- [ ] Continuation resumes at correct step/time (check log).
- [ ] Parallel config valid (no DD error); GPU offload engaged (if used).
- [ ] `tinit`/`init-step` set correctly on restart.

## Phase 8 — Analysis (`01.8`)
- [ ] Trajectory **unwrapped + fitted** (PBC + fit) before MSD/RMSD.
- [ ] Index groups correct (spot-check atom counts).
- [ ] Fitting group chosen (e.g. backbone), not the whole system.
- [ ] Results plausible (RMSD stable, density correct, diffusion in range).
- [ ] Enough sampling; error estimates (block/errbar).

## Phase 9 — Troubleshooting (`01.9`)
- [ ] Read the error message **literally** first.
- [ ] If a crash: capture frames (`nstxout=1`) + simplify to isolate the cause.
- [ ] Check MDP settings vs. FF/system (cutoffs, coupling groups).
- [ ] Don't paper over warnings with `grompp -maxwarn` — in 2026.3 it
  **downgrades "Unknown left-hand" errors for removed/renamed options to
  warnings and runs with the option's *default* value**, silently producing
  wrong physics (see `01.9` §B).

## Universal (every run)
- [ ] FF ↔ water ↔ ion **matched set**.
- [ ] Cutoff < half the shortest box vector.
- [ ] `constraints = h-bonds` (for GPU-resident update on this stack).
- [ ] Checkpointing enabled for long runs.
- [ ] Log read at the end (performance + warnings).
