# 03.1 — Decision Trees

Quick routing: from a goal, pick the MD type and the phase sequence.

## Tree 1 — "What kind of MD do I need?"

```
What is the scientific question?
│
├─ Equilibrium structure/dynamics (folding, ligand bound, diffusion,
│  conformational sampling)?
│   └─► Standard NPT MD ........................ 02.01
│       (NVT for fixed box; NVE only for drift checks)
│
├─ Need to hold the solute while solvent equilibrates?
│   └─► Position restraints (equilibration) ...... 02.02
│
├─ Free-energy difference between two states (ligand A→B, mutation,
│  binding vs unbinding)?
│   └─► Alchemical FEP / TI ...................... 02.03
│       (λ windows + soft-core; gmx bar / gmx wham)
│
├─ Free-energy profile along a reaction coordinate (PMF)?
│   └─► Umbrella sampling ......................... 02.04
│       (or metadynamics / AWH / Colvars ......... 02.05)
│
├─ Escape barriers / enhanced sampling along CVs?
│   └─► Metadynamics / AWH / Colvars .............. 02.05
│
├─ Sample many temperatures / λ states at once (tempering)?
│   └─► Expanded ensemble (serial replica exchange) 02.06
│
├─ Apply a force / drive out of equilibrium (pulling, shear, work→ΔG)?
│   └─► NEMD / pull code .......................... 02.07
│
├─ Vacuum / sparse / over-damped / fast-mode equilibration?
│   └─► Langevin / Brownian dynamics ............... 02.08
│
├─ Heat then cool to escape local minima (conformational search)?
│   └─► Simulated annealing ....................... 02.09
│
├─ Chemistry with bond making/breaking, active site, photochemistry?
│   └─► QM/MM (CP2K) .............................. 02.10
│
├─ Need QM-level accuracy over long times (and a trained model exists)?
│   └─► Neural-network potential (NNPot) ........... 02.11
│
├─ Large system / long times (µs+), membranes, polymers, crowding?
│   └─► Coarse-grained (Martini) ................... 02.12
│
├─ Lipid bilayer / membrane protein / interface?
│   └─► Membrane setup (semi-isotropic P) .......... 02.13
│
└─ Field, rotation, FMM, density, walls, NMR refinement, COM pull?
    └─► Specialized methods ........................ 02.14
```

## Tree 2 — "Which phases do I run, in what order?"

```
Every MD type runs the core pipeline; the type changes specifics:

01.1 Structure prep ─► 01.2 Topology/FF ─► 01.3 Solvation/ions/box
        │
        ▼
01.4 Energy minimization
        │
        ▼
01.5 Equilibration  (NVT ─► NPT)   [position restraints usually ON]
        │
        ▼
01.6 Production MD                    [restraints usually OFF]
        │
        ├──► (extend/restart) ──────────► 01.7
        ▼
01.8 Analysis
        │
        └──► (something failed?) ───────► 01.9 Troubleshooting

Type-specific insertions:
  • Membrane (02.13): anisotropic box + semi-isotropic P at 01.3/01.5.
  • CG (02.12): bead mapping before 01.2; soft-core at 01.4/01.5.
  • FEP (02.03): λ windows + soft-core at 01.6 (one run per window).
  • Umbrella/AWH/MD (02.04/02.05): CV + bias at 01.6 (one run per window).
  • NEMD (02.07): pull coordinate at 01.6 (many replicas).
  • QM/MM (02.10): QM region + CP2K at 01.6.
```

## Tree 3 — "Which thermostat / barostat / integrator?"

```
Production (default):
  `integrator = md` + `tcoupl = v-rescale` + `pcoupl = C-rescale`   [2026]

Need Nose-Hoover (full chain)?
  └─► integrator = md-vv
      (md-vv-avek is validation-only — grompp warns against using it for MD)

Over-damped / vacuum / fast equilibration?
  └─► integrator = sd (Langevin) or bd (Brownian)  ... 02.08
      ('cg' is conjugate-gradient EM, not Langevin)

Membrane?
  └─► pcoupltype = semiisotropic (two compressibility + ref-p)  ... 02.13

Equilibrating (box not yet relaxed)?
  └─► C-rescale (not PR) to avoid box oscillation

Free energy / expanded ensemble / replica exchange?
  └─► NOT compatible with GPU-resident update (this stack)  ... 01.7
```

## Tree 4 — "GPU or CPU on this stack?"

> **Precondition (Phase 0, `03.3`)**: the stack must be in **gromacs** mode
> with eGPU VRAM free (modes are mutually exclusive — `make gromacs`). If
> another mode holds the VRAM, mdrun OOMs at startup; fix the mode, not the
> MDP.

```
Full GPU offload (fastest for large all-atom systems)?
  Requirements: -ntmpi 1, dynamical integrator, classical bonded
  interactions, system size OK.
  Recommended: constraints = h-bonds (all-bonds falls back to CPU).
  └─► gmx mdrun -ntmpi 1 -nb gpu -pme gpu -bonded gpu -update gpu
  NOT available for: FEP, domain decomposition, replica exchange.

Small system / CPU is fine / feature incompatible with GPU update?
  └─► CPU (or partial GPU: -nb gpu -pme gpu) with -ntmpi/-ntomp tuning.
```
