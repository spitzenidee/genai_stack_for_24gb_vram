# 02.13 — Membrane Systems

**When to use**: simulate **lipid bilayers**, **membrane proteins**,
**lipid–protein** interactions, vesicles, or interfaces. Membranes need a
**different box geometry**, **pressure coupling**, and **FF/lipid** choices
than bulk solution.

## Building a bilayer
1. **Lipids**: obtain a lipid bilayer structure (e.g. from the **POPC**
   Martini/CHARMM/SLYB libraries, or the GROMACS membrane examples). Use a
   lipid FF **matched to your water/ions** (e.g. CHARMM36 lipids + TIP3P).
2. **Embed the protein** (if present): orient TM helices along **z**
   (set during curation or with `editconf` — `pdb2gmx` has **no** `-membrane`
   flag in 2026.3), then place the protein in the bilayer (manual or tools
   like the **membrane-embedding** workflow).
3. **Box**: a **rectangular/triclinic box** with the bilayer in the **xy**
   plane and the normal along **z**. The **z dimension** must be large enough
   for bilayer + solvent on both sides (typically ~4–6 nm total).
4. **Solvate + ions** as usual (`01.3`), but the box is **anisotropic**.

## Building a membrane around a protein (iterative lipid packing)

Full embedding + packing + equilibration recipe (InflateGRO, Kandt et al.
2007). The workflow is **FF-agnostic** — the repo uses Berger + GROMOS53A6
for pedagogy; **production should use a modern matched set** (e.g. CHARMM36
lipids + TIP3P).

**Prerequisites**
- Protein **helix axis aligned to z**: `editconf -princ` aligns the longest
  axis to **x**; rotate **90° about y** (`editconf -rotate 0 90 0`) to put it
  on z (the membrane normal).
- A **pre-equilibrated bilayer** coordinate file (e.g. a 128-lipid DPPC
  bilayer). Lipids are usually distributed "broken" across the PBC —
  **rebuild them whole** before packing: `gmx trjconv -s <tpr> -f <in> -o
  <out> -pbc mol -ur compact` (write to a **temp file** — trjconv refuses
  in-place read+write).
- **Lipid FF matched** to the protein FF/water (see above).

**InflateGRO cycle** (document the algorithm; do not copy the GPL script)
1. **Inflate** the bilayer in **xy** by factor **4** (scaling > 1).
2. **Delete** lipids whose P–CA distance to the protein is < **14 Å**
   (deletion **only during inflation**; set the cutoff to **0** for all
   shrinking steps — otherwise you delete the whole membrane).
3. **EM** with **strong protein position restraints**
   (`gmx genrestr -f <protein.gro> -o strong_posre.itp -fc 100000 100000
   100000`), invoked via a **second `#ifdef` block**:
   ```
   #ifdef POSRES
   #include "posre.itp"
   #endif
   #ifdef STRONG_POSRES
   #include "strong_posre.itp"
   #endif
   ```
   with `define = -DSTRONG_POSRES` in the packing EM mdp (and `-r
   <protein.gro>` for the restraint coordinates).
4. **Rebuild broken lipids**: `gmx trjconv -pbc mol` (temp file).
5. **Shrink by 0.95**, EM, repeat — the repo uses **26 rounds** for
   KALP₁₅/DPPC.
6. **Stop at APL ≈ 71 Å²** — InflateGRO *overestimates* APL; the
   experimental fluid-DPPC value is ≈ 62 Å², so do **not** chase the exact
   experimental number.

**Solvation**
- `gmx solvate` (water will enter core voids), then **delete core water**
  (algorithm of `water_deletor.pl`, GPL — document, don't copy): reference
  atom = an ester-region O (O33 in DPPC), middle atom = bilayer center (C50
  in DPPC); delete waters whose OW falls between the two leaflet boundaries;
  `-nwater 3` for 3-site water.

**Ions + EM**
- Standard `gmx genion -neutral` (choose the SOL group), then standard EM.

**NVT**
- Merged thermostat group **`Protein_DPPC`** (`make_ndx`: `1 | 13`) +
  **`Water_and_ions`**:
  ```
  tcoupl   = V-rescale
  tc-grps  = Protein_DPPC  Water_and_ions
  tau-t    = 0.1           0.1
  ref-t    = 323           323
  ```
  **Rationale**: lipids and water diffuse on different timescales — one group
  would give spurious velocity scaling. `tau-t = 0.1` (NVT) / `0.5` (NPT).
  **T above the lipid T_m** (DPPC T_m ≈ 315 K → run 323 K; liquid-crystalline
  state; check the FF-specific T_m error).

**NPT**
- `pcoupltype = semiisotropic` (xy vs z). KB recommends **`C-rescale`** (the
  repo uses Parrinello-Rahman — both work; prefer the KB convention):
  ```
  pcoupl          = C-rescale
  pcoupltype      = semiisotropic
  tau-p           = 5.0
  ref-p           = 1.0   1.0
  compressibility = 4.5e-5    4.5e-5
  nstcomm         = 1
  comm-mode       = Linear
  comm-grps       = Protein_DPPC  Water_and_ions
  ```
  Per-group COM removal (same rationale as the thermostat groups).

**Production & convergence**
- 1 ns is demo-only; **50–100 ns** is typical for converged APL/box vectors.
  Monitor the **Box-X / Box-Y** time series and APL.

**Analysis nuggets**
- **Deuterium order parameter** plateau ≈ **0.2** (carbons 4–8) =
  liquid-crystalline DPPC (`gmx order`).
- **APL** = (Box-X × Box-Y) / lipids per leaflet (pure membrane); for
  protein-containing systems use a grid method (e.g. GridMAT-MD) since the
  protein occupies lateral area.
- **Lateral diffusion** from `gmx msd -lateral z` is a **finite-size
  quantity D_PBC, not D₀** — apply the Yeh & Hummer correction (*J. Phys.
  Chem. B* 108:15873, 2004) for the infinite-system value.

## Pressure coupling (critical)
- Use **`pcoupltype = semiisotropic`**: couple **xy** and **z** separately.
  - Two `compressibility` values (xy, z) and two `ref-p` values (semiisotropic
    **requires** 2 values for both — a single value is a grompp error).
  - xy relaxes the **area per lipid**; z relaxes the **slab thickness**.
- Do **not** use `isotropic` for a bilayer (it would squeeze the membrane
  wrong).
- `pcoupl = C-rescale` (or PR once equilibrated); `tau-p` ~ 2–5 ps.
  - **2026.3 note**: `pcoupl = Isotropic` is a **legacy alias for Berendsen**
    (grompp rewrites it to `Berendsen`; wrong ensemble, discouraged) — it does
    pair with `pcoupltype`, but `C-rescale` remains the recommended default
    for semiisotropic membrane NPT.
- Expect a **longer equilibration** (membranes relax slowly); monitor **area
  per lipid** and **bilayer thickness**.

## Key MDP deltas vs. bulk solution
| Option | Membrane value |
|--------|----------------|
| `pcoupltype` | `semiisotropic` |
| `compressibility` | two values (xy, z) |
| `ref-p` | two values (xy, z) |
| `pcoupl` | `C-rescale` (→ PR after equilibration) |
| `tau-p` | 2–5 ps |
| Box | anisotropic; z = bilayer + 2× solvent |

## Lipid FF & water matching
- Match the **lipid FF** to the **water/ions** (CHARMM36 lipids ↔ TIP3P;
  SLyS ↔ SPC/E; Martini lipids ↔ Martini water). Mixing is a methodology error.

## Pitfalls
- **`isotropic` pressure coupling** on a bilayer → wrong area/thickness.
- Box **z too small** → membrane–membrane image contact across the periodic
  boundary (must have solvent on both sides; avoid the bilayer interacting
  with its own image).
- **Too few lipids** → finite-size / curvature artifacts.
- Forgetting the membrane needs **longer equilibration** (slow area/thickness
  relaxation).
- Wrong lipid–water–ion FF match.
- Protein orientation not along z → poor embedding.
