# 02.16 — Virtual Sites (Mass Centers, Linear Molecules)

**When to use**: model a **linear molecule** (CO₂, N₂, CN⁻) without the
cosine-angle force discontinuity at 180°, place **lone-pair / σ-hole** sites
(halogens, S), build **Drude** polarizable H-bond acceptors, or **repartition
H-mass** onto heavy atoms for a 4 fs step. A virtual site is a particle with
**no mass** whose position is **computed** (not integrated) from a few
"constructing" atoms; it may still carry Lennard-Jones and/or charge, and any
force on it is **projected back** onto the constructing atoms.

> **Terminology caveat**: the literature often calls these "dummy atoms," but
> that term is imprecise — it can also mean a generic *non-interacting*
> particle. A virtual site here **does** interact (LJ/charge); it just has no
> mass.

## Definition (the four properties)
1. **No mass** — it is never integrated.
2. **May participate** in Lennard-Jones and/or Coulomb interactions.
3. **Forces project** onto the constructing atoms.
4. **Position is computed** from the current positions of the constructing
   atoms every step (never stored/integrated).

## Applications
- **Linear molecules** — the force on a `i–j–k` angle contains `cos θ`, which
  is discontinuous as θ fluctuates through 180°. Replacing the atoms with
  virtual sites on a rigid backbone removes the angle term entirely.
- **Lone pairs / σ-holes** — electron-density sites at fixed positions around
  electronegative atoms (halogen σ-holes in OPLS3 / CGenFF, S lone pairs in
  OPLS-AA / OPLS-CM5).
- **Drude polarizable** H-bond acceptors (the Drude oscillator is a virtual
  site).
- **H-mass repartitioning** — move H mass onto the heavy atom (virtual site
  holds the H) to raise the stable time step to ~4 fs.

## Worked example: CO₂ as a rigid diatomic rotor

Convert the triatomic CO₂ into **two massive "mass-center" particles** (M1,
M2) joined by a rigid constraint, with the **C and O atoms as virtual sites**
constructed from M1/M2. Two properties must be preserved: **total mass** and
**moment of inertia**.

**Mass** — CO₂ = 44.0098 amu (C 12.011 + 2×O 15.9994, OPLS-AA masses). Each
mass center takes half: **22.0049 amu**. A new atom type `MCO` carries **no
LJ and no charge** (σ = ε = 0).

**Moment of inertia** — CO₂ is a linear triatomic rotor:
```
I = 2 · m_O · L²   (L = C=O bond length = 0.125 nm)
I = 2 × 15.9994 × 0.125² = 0.49998125 ≈ 0.500 amu·nm²
```
The two mass centers form a rigid diatomic rotor. Solving
`I = (m_M·m_M/m_total)·L_MM²` for the M–M distance:
```
L_MM = sqrt[ I / (m_M·m_M / m_total) ]
     = sqrt[ 0.49998125 / ((22.0049·22.0049)/44.0098) ]
     = sqrt[ 0.49998125 / 11.00245 ] = 0.213173 nm
```
Assign this as a **rigid constraint** (not a harmonic bond — no force constant
to guess):
```
[ constraints ]
; i  j  funct  d
    4  5  1   0.213173
```

**Virtual sites** — C sits at the midpoint (fraction `a = 0.5` of the M–M
distance). Each O sits **beyond** an M: the C is 0.1065865 nm from each M, the
C=O bond is 0.125 nm, so each O is `0.125 − 0.1065865 = 0.0184135` nm past the
M–M distance, i.e. at fraction
`a = (0.213173 + 0.0184135)/0.213173` of the M–M length:
```
[ virtual_sites2 ]
; site  ai  aj  funct   a
     1   4   5      1   1.0851116   ; O1 beyond M2
     2   4   5      1   0.5000      ; C  at midpoint
     3   5   4      1   1.0851116   ; O2 beyond M1
```
**The order of the constructing atoms sets the direction**: site 1 uses `4 5`
(beyond M2), site 3 uses `5 4` (beyond M1). Reversing `ai aj` flips the site to
the other side.

> **D8 — adopt the repo value, note the slip**: the source's own equation
> `(0.213173 + 0.0184135)/0.213173` actually evaluates to **1.086378**, but the
> repo prints **1.0851116** (a **0.27 pm** slip). Use **1.0851116** for
> consistency with the shipped `topol.top`; the difference is negligible for
> this educational model.

**Charges** (Yang & Zhong 2006): O = **−0.35**, C = **+0.70**.
> **Caveat (keep the repo's)**: this is an **educational model**, not a
> validated force field — the Yang & Zhong charges are not endorsed for
> OPLS-AA production use.

## Gas-phase (in vacuo) validation

Place 10 CO₂ in a large box, minimize, then check the **moment of inertia** of
each molecule — the model is physically consistent iff `I_y = I_z = 0.500
amu·nm²` and `I_x = 0` (the x-axis coincides with the M1–M2 constraint):

```
gmx insert-molecules -ci co2.pdb -nmol 10 -box 10 10 10 -o box.pdb
gmx grompp -f em.mdp -c box.pdb -p topol.top -o em.tpr
gmx mdrun -deffnm em -nt 1 -nb cpu
# split each molecule into its own index group:
gmx make_ndx -f em.gro   # > splitres 0  > q
# moments of inertia for one CO2 (group 3 = System_CO2_1):
gmx principal -s em.tpr -f em.gro -n index.ndx -om moi.xvg
```
`moi.xvg` gives the three principal moments. **Verified in the build**:
`I₁ ≈ 0` (along M1–M2), `I₂ = I₃ = 0.5016 amu·nm²` (expected 0.500; the 0.3%
is PDB rounding of M1–M2 to 0.2132 nm). The MoI is a **geometric** property of
the massive M atoms, so this holds on the minimized structure without a stable
MD.

`gmx principal` flags (2026.3): `-s <.tpr/.gro>`, `-f <.xtc/.trr/.gro>`,
`-n <.ndx>`, `-om <.xvg>` (moments), `-a1/-a2/-a3 <.xvg>` (principal axes).
There is **no `-o` option**.

## 2026.3 in-vacuo recipe (the crux — probe-verified)

The repo's in-vacuo recipe uses `cutoff-scheme = group` + `nstlist = 0` +
`ns_type = simple` + `pbc = no`. **All of that is gone in 2026.3** — the
`group`/`ns` schemes were removed (GROMACS 2020+), leaving **Verlet only**, and
Verlet **does not support `pbc = no`**:

| Probe | Result (2026.3-dev) |
|-------|---------------------|
| `cutoff-scheme = group` | **FAIL** — "The group cutoff scheme has been removed since GROMACS 2020. Please use the Verlet cutoff scheme." |
| `pbc = no` (Verlet) | **FAIL** — "With Verlet lists only full pbc or pbc=xy with walls is supported" |
| `rcoulomb = rvdw = 0` | **FAIL** — "At least one cutoff radius (rcoulomb or rvdw) should be > 0 when using the Verlet cutoff scheme" |
| `pbc = xy` (no walls) | **FAIL** — same "full pbc or pbc=xy with walls" message |
| `pbc = xyz` + `rcoulomb = rvdw = 100` | **FAIL** — "The cut-off length is longer than half the shortest box vector" |
| **`pbc = xyz` + `rcoulomb = rvdw = 4.5`** | **PASS** |

**Working in-vacuo recipe** (10 nm box; for a box of side `L`, use a cutoff
`< L/2` minus the Verlet buffer — for 10 nm the max is ≈ 4.75 nm, use **4.5**):
```
coulombtype   = cutoff
rcoulomb      = 4.5      ; just under half the 10 nm box (max ~4.75)
rvdw          = 4.5
pbc           = xyz
```
With `pbc = xyz` and a cutoff just under half the box, every pair interacts via
the minimum-image convention — the practical substitute for the old "infinite
cutoffs." The molecules are far apart in a large box, so inter-molecular
forces are negligible and each CO₂ rotates freely.

**`comm-mode = angular`** (angular-momentum conservation, used by the repo for
the MD) emits a warning in a periodic system — *"Removing the rotation around
the center of mass in a periodic system"* — that **fails `grompp` by default**.
Pass **`-maxwarn 2`**:
```
gmx grompp -f md.mdp -c em.gro -p topol.top -o md.tpr -maxwarn 2
gmx mdrun -deffnm md -nt 1 -nb cpu
```
The repo's `-nt 1 -nb cpu` (group-scheme GPU limitation) no longer applies in
2026.3; keep `-nt 1` (50 particles don't parallelize) but `-nb cpu` is
optional.

## Key MDP deltas vs. standard MD
| Option | In-vacuo value (2026.3) | Why |
|--------|------------------------|-----|
| `pbc` | `xyz` (large box) | `pbc = no` unsupported by Verlet |
| `rcoulomb` / `rvdw` | `< L/2` (e.g. 4.5 for 10 nm) | must be > 0 and < half box |
| `coulombtype` | `cutoff` | no PME in a finite gas box |
| `comm-mode` | `angular` | conserve angular momentum (needs `-maxwarn`) |
| `cutoff-scheme` | *(omit — Verlet is the only scheme)* | `group`/`ns` removed |

## Pitfalls
- **`pbc = no` / `cutoff-scheme = group`** — removed; use `pbc = xyz` + a
  cutoff just under half the box.
- **Cutoff ≥ half the box** → grompp fatal ("longer than half the shortest box
  vector"). Leave a margin for the Verlet buffer (max ≈ 4.75 nm for a 10 nm box).
- **`rcoulomb = rvdw = 0`** → grompp fatal under Verlet (needs a radius > 0).
- **`comm-mode = angular`** in a periodic box → warning that fails grompp
  without `-maxwarn`.
- **MD instability of the educational model**: the C–O virtual-site pair sits in
  the OPLS LJ repulsive wall (r = 0.125 nm ≪ σ_C-O ≈ 0.325 nm) with **no bonded
  exclusions** (there are no `[ bonds ]`), so the projected forces can break the
  M1–M2 constraint during MD (LINCS warning). This is a property of the
  tutorial's model (identical under the old infinite-cutoff recipe), **not** a
  2026.3 regression — validate with the **static** MoI check, which is geometric.
- **Virtual-site direction**: the `ai aj` order in `[ virtual_sites2 ]` sets
  which side the site lands on; swap them to mirror it.
- **`[ atomtypes ]` mass is irrelevant** for a virtual site — the mass is set in
  `[ atoms ]` (and virtual sites carry 0).
