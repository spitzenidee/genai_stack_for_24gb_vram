# 02.14 — Specialized Methods

A catalog of less-common GROMACS simulation types. Each is a **delta** on top
of the standard pipeline (`01.1–01.6`) plus a specific MDP block.

## Electric fields (2026.3 module)
- Apply a **uniform external electric field** (e.g. to drive ion transport,
  study field effects on folding). Can be static, oscillating, or pulsed.
- **The old `electric-field-pulse` option is gone.** Each axis is an
  **independent** field described by **four reals**
  `electric-field-x/y/z = E0 omega t0 sigma` (amplitude, angular frequency
  rad/ps, phase offset, pulse width). A static field is `E0 0 0 0`; an
  oscillating field sets `omega`; a pulse sets `sigma`.
- Analysis: current, dipole (`gmx dipoles` — **`gmx dipole` is gone**), ion flux.

## FMM (Fast Multipole Method, 2026.3 module)
- An **alternative to PME** for long-range electrostatics (useful in some
  large/irregular systems or specific boundary conditions).
- **2026.3 API**: FMM is a module (`fmm`). Enable with
  `fmm-backend = exafmm` (or `fmsolvr`) **and** `coulombtype = FMM` — the
  backend alone is insufficient (grompp error: "FMM requires Coulomb
  interaction type to be FMM"). **Not** the default — PME is standard.
- Verify accuracy vs. PME for your system before relying on it.

## Density-guided simulation (2026.3 module)
- Bias/steer the system toward a target **density** (e.g. match an
  experimental density profile, or maintain a local density).
- **2026.3 API**: module `density-guided-simulation`:
  ```
  density-guided-simulation-active = yes
  density-guided-simulation-group = Protein
  density-guided-simulation-similarity-measure = inner-product
      ; or relative-entropy / cross-correlation
  density-guided-simulation-atom-spreading-weight = unity
  density-guided-simulation-force-constant = 1e9
  density-guided-simulation-gaussian-transform-spreading-width = 0.2
  density-guided-simulation-reference-density-filename = ref.mrc
  density-guided-simulation-nst = 1000
  ; nstcalcenergy MUST be a multiple of density-guided-simulation-nst
  ; (grompp errors otherwise); this overrides the production nstcalcenergy = 1:
  nstcalcenergy = 1000
  density-guided-simulation-normalize-densities = yes
  density-guided-simulation-shift-vector = 0 0 0
  ```
- Use to enforce a structural density constraint during sampling.

## Test-particle insertion (2026.3)
- Insert **test particles** (e.g. water, ions) to probe the local chemical
  potential / free energy of insertion (related to the test-particle
  integration in the free-energy code).
- TPI = `integrator = tpi` (or `tpic`) + `rtpi` (insertion radius, default
  0.05). `mdrun -tpi`/`-tpid` write the insertion-distribution outputs.
  **Not** `free-energy = expanded` + `mc-temperature` — that is the
  expanded-ensemble / Wang-Landau machinery (see `02.06`).
- `GMX_TPI_DUMP` env var dumps low-energy insertion configs.
- Used for chemical-potential / solvation-free-energy estimates.

## NMR refinement
- Refine a structure against **NMR restraints** (distance, dihedral,
  NOE) by adding them as restraints during MD.
- MDP (2026.3): the **`disre` family** — `disre` (`no`/`simple`/`ensemble`),
  `disre-weighting`, `disre-mixed`, `disre-fc` (force constant), `disre-tau`,
  `nstdisreout`. (The old `nmr-*` options are gone.)
- Input: NMR restraint files (distance/dihedral, via the `disre` restraints).
  Analysis: `gmx nmr` (restraint violations from the `.edr`), plus
  `gmx nmeig`/`nmens`/`nmtraj`.

## Walls
- Apply **wall potentials** (e.g. a confining box, a channel, a surface) to
  keep particles in a region or model a boundary.
- MDP (2026.3):
  - `nwall` — **explicit** number of walls (0/1/2). `wall-atomtype` and
    `wall-density` each need exactly `nwall` values.
  - `wall-type` — enum `9-3` / `10-4` / `12-6` / `table` (the LJ wall
    potential form; **not** `cubic`/`cylinder`/`dodecahedron`).
  - `wall-r-linpot` — a **single real** (the linear-potential start distance
    from the wall), **not** a per-wall list.
  - `wall-atomtype` — the wall atom type(s), one per wall (must be defined in
    the topology, else grompp error "Specified wall atom type W1 is not defined").
  - `wall-density` — a **per-wall list** (one density value per wall).
  - `wall-ewald-zfac` (default 3).
- **PBC / Verlet constraint**: walls require `pbc = xy` (unbounded z). With
  `cutoff-scheme = Verlet` (the only value in 2026.3), a pbc=xy wall box must
  have **`nwall = 2`** — otherwise grompp errors "With Verlet lists only full
  pbc or pbc=xy with walls is supported". Example (2 walls, z-bounded):
  ```
  pbc = xy
  nwall = 2
  wall-type = 12-6
  wall-r-linpot = 0.1
  wall-atomtype = W1 W1
  wall-density = 1000 1000
  ```
- Use for nanopores, confinement studies, or keeping a solute centered.

## Choosing among them
- **Field-driven transport** → electric fields (`electric-field-x/y/z`).
- **Long-range electrostatics alternative** → FMM (`fmm-backend` +
  `coulombtype = FMM`, validate vs. PME).
- **Density constraint** → density-guided (`density-guided-simulation-*`).
- **Boundary/confinement** → walls (`wall-*`).
- **NMR-driven refinement** → NMR refinement.
- **COM drag** → the pull code (`02.07`). **The old `com-pull`,
  `enforced-rotation`, and `shell` MDP options are gone in 2026.3.**

## General pitfalls
- These are **specialized** — read the specific manual section and validate on
  a small test before a production run.
- Most are **incompatible with GPU-resident update** and some with domain
  decomposition (→ `01.7`); check the feature's constraints.
- Report the method + parameters clearly (reproducibility).
