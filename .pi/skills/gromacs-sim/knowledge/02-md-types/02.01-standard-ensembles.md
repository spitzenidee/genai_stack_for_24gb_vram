# 02.01 — Standard MD: NVE / NVT / NPT / NPH

**When to use**: the default for essentially all equilibrium sampling —
protein folding/unfolding, ligand binding (bound state), solvent behavior,
diffusion, conformational dynamics.

## Ensembles

| Ensemble | Conserved / controlled | Coupling | Typical use |
|----------|------------------------|----------|-------------|
| **NVE** | N, V, E (microcanonical) | none | Energy-drift validation; short checks. |
| **NVT** | N, V, T (canonical) | thermostat | Equilibration stage A; fixed-box production. |
| **NPT** | N, P, T (isothermal-isobaric) | thermostat + barostat | **Default production** (box relaxes to correct density). |
| **NPH** | N, P, H (microcanonical barostat) | barostat only | Rare; constant-pressure without thermostat. |

## Integrator ↔ thermostat/barostat compatibility

| `integrator` | Thermostat | Barostat | Notes |
|--------------|-----------|----------|-------|
| `md` (leap-frog, default) | v-rescale, berendsen, nose-hoover(1) | C-rescale, Berendsen, PR | Default. NH chain length 1 only. **Andersen is NOT supported with `md`** (grompp error). |
| `md-vv` (velocity Verlet) | nose-hoover (full chain), v-rescale | MTTK (deprecated), PR (`Isotropic` = legacy Berendsen alias, discouraged) | Use for Nose-Hoover / MTTK. MTTK requires Nose-Hoover temperature control; **constraints allowed**. |
| `md-vv-avek` | as `md-vv` | as `md-vv` | **Validation-only integrator** (grompp warns: "implemented primarily for validation purposes; for molecular dynamics, you should probably be using md or md-vv"). Not for production. |
| `sd` (stochastic/Langevin) | Langevin (friction+noise), **Andersen**, Andersen-massive | — | `tau-t` = inverse friction, `ref-t`, `ld-seed`; `tcoupl`/`nsttcouple` ignored. See `02.08`. |
| `bd` (Brownian) | Brownian (overdamped), **Andersen** | — | `bd-fric`, `ref-t`, `ld-seed`. See `02.08`. |
| `steep` / `cg` / `l-bfgs` / `nm` | — | — | Energy minimization / optimization only. |
| `mimic` | — | — | QMMM (MiMiC) simulations — see `02.10`. |

**Removed integrators (2026.3)**: `langevin`, `brownian`, `npt`, `qmmm` — no
longer valid values of `integrator`. Langevin is now `sd`, Brownian is `bd`.
Test-particle insertion is `integrator = tpi` (or `tpic`) + `rtpi` (insertion
radius — an MDP option, **not** an integrator); `mdrun -tpi`/`-tpid` write the
outputs. **Not** `free-energy = expanded` + `mc-temperature` (that is the
expanded-ensemble / Wang-Landau machinery, see 02.06).

**2026 recommended defaults**: `integrator = md`, `tcoupl = V-rescale`,
`pcoupl = C-rescale`.

## MDP deltas vs. a bare file

- **NVE**: `tcoupl = no`, `pcoupl = no`. (Use only for drift checks.)
- **NVT**: `tcoupl = v-rescale`, `tau-t`, `ref-t`, `tc-grps`; `pcoupl = no`.
- **NPT**: NVT settings **plus** `pcoupl = C-rescale`, `pcoupltype`, `tau-p`,
  `compressibility`, `ref-p`, `refcoord-scaling`.
- **NPH**: `tcoupl = no`, `pcoupl = C-rescale` (or PR).

## Setup (phases)
Standard pipeline `01.1 → 01.6`. NVT = Phase 5A, NPT = Phase 5B + Phase 6.

## Analysis
Standard (`01.8`): energy, RMSD, RMSF, gyrate, hbond, rdf, msd, etc.
- **NVE**: verify total-energy drift is small (kJ/mol/ps).
- **NPT**: verify pressure/density stability.

## Pitfalls
- Using **Berendsen** for production (incorrect ensemble) — use v-rescale /
  C-rescale (2026 guidance).
- **PR barostat** on an unequilibrated system → oscillations → crash (use
  C-rescale first).
- Coupling a **tiny group** to its own bath → `grompp` no longer errors (the
  old "fewer than 10% of the atoms" check is gone); it only prints the
  degrees-of-freedom NOTE. Merge small groups.
- Forgetting `refcoord-scaling = com` in NPT with position restraints (enum
  `no`/`com`/`all` — `yes` is invalid).
- NVE with a thermostat accidentally on (not a true NVE).
