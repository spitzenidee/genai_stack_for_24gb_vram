# 02.02 — Position-Restrained MD

**When to use**: keep the solute near a reference structure while the solvent
equilibrates, during staged relaxation, or to hold a region fixed (e.g. a
protein backbone while a ligand/solvent relaxes). The workhorse of
**equilibration**.

## Mechanism
- `[ position_restraints ]` adds a harmonic spring pulling each restrained atom
  toward a reference position `R_i`:
  `V = ½ k (r_i − R_i)²` (per component, with `fcx/fcy/fcz`).
- Force constant `k` in **kJ/mol/nm²**.
- Reference positions come from a posre file (generated from a structure).

## Setup
1. **Generate the posre file** (from the structure you want to hold):
   ```bash
   gmx genrestr -f em.gro -o protein.posre.itp -fc 1000
   ```
   - `-fc 1000` (default) is a strong restraint.
   - `-n index.ndx` to restrain a subset (e.g. a backbone index group).
2. **Include it in the correct moleculetype** in the `.top`.
3. **Pass reference coordinates to grompp** with `-r <structure.gro>` (a
   structure file, **not** the `.itp`) for the runs that should be restrained
   (usually NVT + NPT equilibration; **not** plain production).
4. **NPT only**: set `refcoord-scaling = com` so the reference coords scale
   with the box (enum: `no`/`com`/`all`).

## Force-constant guidance

| Stage | `fc` (kJ/mol/nm²) | Intent |
|-------|-------------------|--------|
| Initial NVT/NPT (clash relief) | 1000 (backbone) / 1000 (all heavy) | Hold firmly. |
| Mid relaxation | 250 | Let side chains/solvent settle. |
| Late relaxation | 50–100 | Near-free. |
| Production | 0 (off) | Free sampling. |

## Staged relaxation protocol
1. NVT with `fc=1000` (backbone) — 0.1–0.5 ns.
2. NPT with `fc=1000` — 0.5–2 ns.
3. (Optional) NPT with `fc=250`, then `fc=50` — 0.5 ns each, re-grompp between.
4. Production with restraints **off**.
- Re-grompp between stages (the posre file / `-r` changes).

## Flat-bottomed restraints (variant)
- `flat-bottomed` position restraints: no force **inside** a radius `r_fb`,
  harmonic outside. Useful to keep a molecule in a region without pinning it.
- Can combine normal + flat-bottomed on the same atom (same reference).

## MDP deltas
- No special MDP keys beyond the standard ones; the restraint lives in the
  **topology** (posre file + `-r` reference coords at grompp).
- `refcoord-scaling = com` in NPT.

## Analysis
- Standard (`01.8`). Track solute **RMSD vs. reference** to confirm the
  restraint is holding; watch that restrained atoms aren't accumulating huge
  restraint energy.

## Pitfalls
- Posre file in the **wrong moleculetype** → `Atom index (n) in
  position_restraints out of bounds (1-N)`.
- Forgetting `refcoord-scaling = com` in NPT → restraints fight box scaling.
- Restraints to coordinates **too different** from the current structure →
  large forces → blowing up.
- Leaving strong restraints on in "production" → not free sampling.
- Restraint energy spiking in `gmx energy` → check the reference structure.
