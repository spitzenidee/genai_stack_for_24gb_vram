# 02.15 — Biphasic (two-liquid) Interfaces

**When to use**: simulate **solute partitioning** between two coexisting
liquid phases (e.g. octanol/water as a logP proxy) or **interface dynamics**.
The simulation itself is **standard MD** — only the **construction** differs
(plus COM-motion groups, → `02.13`).

## Prerequisites
- A single-molecule coordinate + topology file for each phase (e.g. one
  cyclohexane; for production use a modern FF — OPLS/CHARMM cyclohexane or
  octanol). The repo's `chx.top` is **GROMOS43A1/PRODRG** (legacy,
  united-atom CH2 with zero charges) — do not use for production.
- Standard phases `01.1–01.3` apply to each pure liquid; the box is
  **anisotropic** once the two layers are stacked.

## Building a pure-liquid box (two methods)

**Method A — `gmx insert-molecules`** (random insertion)
```
gmx insert-molecules -ci chx.gro -nmol 1200 -box 5 5 5 -o chx_box.gro
```
- `-nmol` is a **maximum, not a guarantee** — inspect the reported count
  (the repo placed 1114 of 1200).
- Default vdW radii used by `insert-molecules`/`solvate` **changed in
  GROMACS 5.0**, so counts vary between versions; insertion is randomly
  seeded.
- 2026.3 flags: `-f` (existing coords), `-ci` (molecule to insert), `-ip`
  (positions), `-box` (vector), `-nmol`, `-conc`. **`-s`/`-maxattempt` are
  gone** (per KB I-10).

**Method B — `gmx genconf`** (perfect lattice)
```
gmx genconf -f chx.gro -nbox 8 8 8 -o chx_box.gro
```
- `-nbox 8 8 8` = 512 mols. Requires a **properly boxed input** (or a
  `-dist` vector to space the replicas).
- **Highly artificial** (perfect lattice) → **much longer equilibration** to
  reach a liquid state.

## Equilibrate the pure box first
- NVT + NPT **before** using the box as a building block. The repo
  equilibrates 466 cyclohexane in a 4.3-nm box: NVT then **10 ns NPT at
  298 K** (`chx_10ns.gro`).

## Seat the oil box in a larger box
- Extend the box along **z** and keep the oil at its original position:
  ```
  gmx editconf -f chx_10ns.gro -o chx_newbox.gro \
      -box 4.30795 4.30795 8.6159 -center 2.153975 2.153975 2.153975
  ```
  The 4.30795-nm cube has geometric center **(2.153975, 2.153975,
  2.153975)** (= 4.30795/2); doubling z gives 8.6159.
- Water added by `solvate` is **continuous with the "bottom" via z-PBC** —
  that is **correct, not a bug**.

## Prevent water in the oil phase
- Copy `vdwradii.dat` from `$GMXLIB` into the working dir, **raise the C
  radius 0.17 → 0.35**, then:
  ```
  gmx solvate -cp chx_newbox.gro -cs spc216.gro -p chx.top -o chx_solv.gro
  ```
- A few **stray waters** may remain in the oil — they are expelled by a
  short equilibration.

## Place a solute
- **In the oil phase**: `gmx solvate -cs <oilbox.gro>` — the equilibrated
  oil box *is* the solvent template.
- **In the aqueous phase**: center the solute at **¾ of the z-box length**
  (8.6159 × 0.75 = **6.461925**), then `gmx solvate -cp solute -cs
  oilbox`:
  ```
  gmx editconf -f peptide.gro -o peptide_newbox.gro \
      -box 4.30795 4.30795 8.6159 -center 2.153975 2.153975 6.461925
  gmx solvate -cp peptide_newbox.gro -cs chx_newbox.gro -o peptide_chx.gro
  ```

## Expand the oil layer
- `gmx genconf -f chx_10ns.gro -nbox 2 2 2` (cubic) or `-nbox 2 2 1`
  (tetragonal, xy only — do **not** replicate along z).

## MDP deltas vs. standard
| Option | Biphasic value |
|--------|----------------|
| `comm-grps` | per-layer groups (oil vs water+ions) — see `02.13` |
| `pcoupltype` | `isotropic` is fine for a flat slab; `semiisotropic` if z must relax independently |
| Box | anisotropic; z = oil layer + aqueous layer |

The only MD-specific consideration is **COM-motion removal groups** — treat
each layer separately (→ `02.13`, `01.3`).

## Analysis
- **Partitioning**: count solute residence in each layer over time (→ `01.8`).
- **Interface position / thickness**: density profile along z (`gmx
  density`).
- Standard MD analysis otherwise.

## Pitfalls
- **Water leaking into the oil phase** — use the `vdwradii.dat` C-radius
  trick (0.17 → 0.35) and a short equilibration to expel strays.
- **`insert-molecules` `-nmol` is a maximum** — inspect the actual count.
- **`genconf` lattice is artificial** — budget extra equilibration.
- Forgetting the box is **anisotropic** / the water is PBC-continuous with
  the bottom.
- Legacy FF (GROMOS43A1/PRODRG) used for production.
- Water at the "bottom" of the box is **not** a defect (z-PBC continuity).
