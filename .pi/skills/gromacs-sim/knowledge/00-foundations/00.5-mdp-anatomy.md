# 00.5 — MDP File Anatomy

## Conventions

- One `.mdp` **per phase** (em.mdp, nvt.mdp, npt.mdp, md.mdp, plus type-specific
  files). Keep them separate — do not reuse one file across phases.
- **Units**: nm, ps, K, bar, kJ/mol, kJ/mol/nm, kJ/mol/nm², amu.
- **Dash/underscore interchangeable** (`tau-t` ≡ `tau_t`).
- In the reference, the **first listed option is the default**; defaults are
  shown in parentheses.
- Comments with `;`.
- `gmx grompp` will warn if you omit critical options. (No sample `.mdp`
  ships with the install — verified absent in 2026.3.)

## Section map (option → what it controls)

| Section | Representative options |
|---------|------------------------|
| **Preprocessing** | `include`, `define` |
| **Run control** | `integrator`, `nsteps`, `dt`, `nstcomm` |
| **Langevin / Brownian** | `integrator = sd` (Langevin: `tau-t` = inverse friction, `ref-t`, `ld-seed`; `tcoupl`/`nsttcouple` ignored), `integrator = bd` (Brownian: `bd-fric`, `ref-t`, `ld-seed`). **`tau-bfric` is gone** — Langevin is now the `sd` integrator. |
| **Energy minimization** | `emtol`, `emstep` |
| **Test particle insertion (TPI)** | `integrator = tpi` (or `tpic`) + `rtpi` (insertion radius); `mdrun -tpi`/`-tpid` write the insertion-distribution outputs. **Not** `free-energy = expanded` + `mc-temperature` — that is the expanded-ensemble / Wang-Landau machinery (see 02.06). |
| **Output control** | `nstxout`, `nstxout-compressed`, `nstenergy`, `nstlog`, `nstcalcenergy`, `nstdhdl` (**`nstxout-steps`/`nstwrite`/`nstframe`/`nsthistogram` are gone**; `nstcheckpoint` is **obsolete — grompp prints `Ignoring obsolete mdp entry 'nstcheckpoint'` and it never reaches the TPR**; the checkpoint interval is `mdrun -cpt`, in **minutes**) |
| **Neighbor searching** | `cutoff-scheme` (**`Verlet` only** — `grid`/`group` removed), `nstlist`, `rlist`, `verlet-buffer-tolerance`. **The `ns` option is gone; `ns_type` is obsolete** (grompp prints `Ignoring obsolete mdp entry 'ns_type'` and ignores it — do not include it; older tutorials' `ns_type = grid` is a no-op). |
| **Electrostatics** | `coulombtype` (PME), `rcoulomb`, `epsilon-r`, `epsilon-rf`, `pme-order`, `fourierspacing`, `ewald-rtol` (**`rfcutoff`/`eps-r`/`eps-rf`/`coulomb-verlet-scheme`/`pme-spacing`/`dispersion-correction` are gone**) |
| **Van der Waals** | `vdwtype` (cut-off), `rvdw`, `vdw-modifier` |
| **Ewald** | (PME settings, overlaps electrostatics) |
| **Temperature coupling** | `tcoupl`, `tau-t`, `ref-t`, `tc-grps`, `nsttcouple`, `nh-chain-length`, `ensemble-temperature*` |
| **Pressure coupling** | `pcoupl`, `pcoupltype`, `tau-p`, `compressibility`, `ref-p`, `nstpcouple`, `refcoord-scaling` |
| **Simulated annealing** | `annealing` (enum `no`/`single`/`periodic`), `annealing-npoints` (per group), `annealing-time` (list), `annealing-temp` (list). **`annealing-t`/`annealing-p` are gone.** Note: this build's grompp accepts arbitrary strings for `annealing` without validation — typos are not caught. |
| **Velocity generation** | `gen-vel`, `gen-temp`, `gen-seed` |
| **Bonds / constraints** | `constraints` (enum `none`/`h-bonds`/`all-bonds`/`h-angles`/`all-angles`), `lincs-order`, `lincs-iter`, `lincs-warnangle`. **Old `lincs-itmax`/`lincs-warnstep` are gone** (renamed to `lincs-iter`/`lincs-warnangle`); `lincs-warnsize`/`lincs-mtol`/`lincs-algo` are also gone. |
| **Energy group exclusions** | `energygrps` |
| **Walls** | `nwall` (0/1/2, **explicit**), `wall-type` (enum `9-3`/`10-4`/`table`/`12-6`), `wall-atomtype` (**`nwall` values**, must be defined in topology), `wall-density` (**`nwall` values**), `wall-r-linpot` (single real), `wall-ewald-zfac`. Requires `pbc = xy`; with `cutoff-scheme = Verlet` (the only value) a pbc=xy wall box needs **`nwall = 2`** (else "only full pbc or pbc=xy with walls is supported"). **Old `wall`/`wall-r`/`wall-epsilon`/`wall-sigma` are gone.** |
| **AWH** | `awh` (yes/no), `awh-potential` (`convolved`/`umbrella`), `awh1-ndim`, `awh1-dimN-coord-provider` (`pull`/`fep-lambda`), `awh1-dimN-coord-index`, `awh1-dimN-force-constant`, `awh1-dimN-start/end/diffusion`, `awh1-target` (`constant`/`cutoff`/`boltzmann`/`local-boltzmann`), `awh1-growth`, `awh1-growth-factor`, `awh1-error-init`, `awh1-histogram-tolerance`, `awh1-target-beta-scaling`, `awh1-target-cutoff`, `awh1-user-data`, `awh1-share-group`, `awh-nstout`, `awh-seed`, `awh-share-multisim`, `ensemble-temperature-setting` + `ensemble-temperature` (required for AWH) |
| **Enforced rotation** | `rotation` (yes/no) + `rot-*` API: `rot-ngroups`, `rot-group0`, `rot-type0` (`iso`/`pm`/`rm`/`rm2`/... + `-pf` variants), `rot-vec0`, `rot-pivot0`, `rot-rate0`, `rot-k0`, `rot-massw0`, `rot-eps0`, `rot-fit-method0`, `rot-nstrout`. **The old `enforced-rotation` block name is wrong.** |
| **NMR refinement** | `disre` (`no`/`simple`/`ensemble`), `disre-weighting`, `disre-mixed`, `disre-fc`, `disre-tau`, `nstdisreout` (analysis: `gmx nmr`/`nmeig`/`nmens`/`nmtraj`). **The old `nmr-*` options are gone — the 2026.3 API is the `disre` family.** |
| **Free energy** | `free-energy` (enum `no`/`yes`/`static`/`slow-growth`/`expanded`), `couple-lambda0`/`couple-lambda1` (enum `vdw-q`/`vdw`/`q`/`none`), `init-lambda`, `init-lambda-state` (window index), `delta-lambda`, `coul-lambdas`, `vdw-lambdas`, `bonded-lambdas`, `restraint-lambdas`, `mass-lambdas`, `temperature-lambdas`, `fep-lambdas`, `sc-function` (`beutler`/`gapsys`), `sc-r-power`, `sc-coul` (yes/no), `sc-power`, `sc-sigma`, `sc-alpha`, `sc-gapsys-*`, `dhdl-derivatives` (yes/no), `dhdl-print-energy`, `calc-lambda-neighbors` (int), `nstdhdl`. **`free-energy-group`, `sc-r`, `sc-n`, `sc-zero`, `sc-coulomb`, `fep-lambda`, `dhdl-file` are gone.** |
| **Expanded ensemble** | `free-energy = expanded` (required precondition!), `integrator = md-vv` (required), `nstexpanded`, `lmc-stats` (`no`/`metropolis-transition`/`barker-transition`/`minvar`/`wang-landau`/`weighted-wang-landau`), `lmc-move` (`no`/`metropolis`/`barker`/`gibbs`/`metropolized-gibbs`), `lmc-weights-equil`, `lmc-seed`, `lmc-repeats`, `lmc-gibbsdelta`, `lmc-forced-nstart`, `mc-temperature`, `wl-ratio`, `wl-scale`, `wl-oneovert`, `init-wl-delta`, `weight-equil-*`, `symmetrized-transition-matrix`, `nst-transition-matrix`. **`lmc`/`expanded`/`lmc-mc-move` are gone — the option is `lmc-move`.** |
| **Non-equilibrium MD / pulling** | `pull` (yes/no), `pull-ncoords`, `pull-ngroups`, `pull-groupN-name`/`-weights`/`-pbcatom`, `pull-coordN-type` (`umbrella`/`constraint`/`constant-force`/`flat-bottom`/`flat-bottom-high`/`external-potential`), `pull-coordN-geometry` (`distance`/`direction`/`cylinder`/`direction-periodic`/`direction-relative`/`angle`/`dihedral`/`angle-axis`/`transformation`), `pull-coordN-groups`, `pull-coordN-vec`, `pull-coordN-dim`, `pull-coordN-k`, `pull-coordN-init`, `pull-coordN-rate`, `pull-coordN-start` (yes/no), `pull-coordN-potential-provider`, `pull-coordN-expression`, `pull-constr-tol`, `pull-print-com`, `pull-nstxout`, `pull-nstfout`. **`pull-coord` (int) and `pull-coord1-increment` are gone; `pull-coord1-geometry` no longer has `COM`.** |
| **Electric fields** | `electric-field-x/y/z` — each takes **four** reals: `E0 omega t0 sigma` | 
| **QM/MM** | `qmmm-cp2k-active`, `qmmm-cp2k-qmgroup`, `qmmm-cp2k-qmmethod` (PBE, PBE-D3, BLYP, BLYP-D3, PBE0, PBE0-D3, B3LYP, B3LYP-D3, CAM-B3LYP, ...), `qmmm-cp2k-qmfilenames`, `qmmm-cp2k-qmcharge`, `qmmm-cp2k-qmmultiplicity`. **Old flat `qmmm-*` names are gone (`Unknown left-hand`); bare `qmmm` is still recognized but hard-errors (`The QMMM integration you are trying to use is no longer supported`); the module prefix is `qmmm-cp2k-`.** |
| **Viscosity** | (no options — `calcvf` removed in 2026.3) |

## The options that matter most (by phase)

- **EM**: `integrator=steep`, `emtol`, `emstep`.
- **NVT**: `tcoupl`, `tau-t`, `ref-t`, `tc-grps`, `gen-vel`, `constraints`.
- **NPT**: `pcoupl`, `pcoupltype`, `tau-p`, `compressibility`, `ref-p`,
  `refcoord-scaling`.
- **Production**: `integrator`, `dt`, `nsteps`, output `nst*`,
  `cutoff-scheme`, `nstlist`, `rvdw`/`rcoulomb`. Checkpoint interval is
  `mdrun -cpt` (minutes) — not an MDP option.

## Cut-off & neighbor-search invariants

- `cutoff-scheme = Verlet` (the **only** value in 2026.3 — `grid` and `group` are
  removed; the old `ns` option is gone; `ns_type` is **obsolete** — grompp
  ignores it with a note, so drop it from MDPs ported from older releases).
- **Minimum-image rule**: `rlist` (and `rvdw`/`rcoulomb`) must be **< half the
  shortest box vector**. Violation → `grompp` error or self-interaction
  artifacts.
- `verlet-buffer-tolerance` controls the pair-list buffer (energy-drift vs
  speed trade-off).
- `nstlist` = how often the neighbor list is rebuilt (default **10**; larger =
  faster but more drift for mobile systems; `0` is rejected with Verlet lists
  — "With Verlet lists nstlist should be larger than 0").

## Thermostat / barostat option sets (2026 guidance)

- **Thermostat**: `tcoupl = V-rescale` (recommended, correct canonical
  ensemble, works at `tau-t=0`). Alternatives: `Nose-Hoover` (correct NVT,
  use with `md-vv`), `Andersen` / `Andersen-massive` (velocity randomization —
  **not supported with `integrator = md`**; use with `sd` or `bd` and set
  `nstcomm = 1`), `Berendsen` (**discouraged for new production**).
  Enum: `No`/`Berendsen`/`Nose-Hoover`/`yes`/`Andersen`/`Andersen-massive`/
  `V-rescale` (case-insensitive).
- **Barostat**: `pcoupl = C-rescale` (recommended, correct NPT, equilibration
  + production). Alternatives: `Parrinello-Rahman` (production, can oscillate
  if starting far from equilibrium), `Isotropic` (**legacy alias for
  Berendsen** — grompp rewrites it to `Berendsen`; wrong ensemble,
  discouraged), `MTTK` (**deprecated — requires Nose-Hoover temperature
  control (`tcoupl = nose-hoover`), which needs `md-vv`; constraints
  allowed**), `Berendsen` (**discouraged**). Enum: `No`/`Berendsen`/
  `Parrinello-Rahman`/`Isotropic`/`MTTK`/`C-rescale`.
- `pcoupltype`: `isotropic` (default), `semiisotropic` (membranes: x/y vs z),
  `anisotropic`, `surface-tension`.
- `refcoord-scaling = com` (or `all`) in NPT when using position restraints
  (scales restraint reference coords with the box). Enum is `no`/`com`/`all` —
  **`yes` is invalid**.

## Free-energy option sets (see `02.03`)

- `free-energy = yes` + `couple-lambda0`/`couple-lambda1` (which terms are
  coupled at λ=0/λ=1; enum `vdw-q`/`vdw`/`q`/`none`). **`free-energy-group`
  is gone.**
- **Lambda vector**: separate arrays per term (`coul-lambdas`, `vdw-lambdas`,
  `bonded-lambdas`, `restraint-lambdas`, `mass-lambdas`, `temperature-lambdas`,
  `fep-lambdas`).
- **Soft-core**: `sc-function = beutler` (default) + `sc-r-power` (e.g. 6),
  `sc-coul` (yes/no), `sc-power`, `sc-sigma`; or `sc-function = gapsys` +
  `sc-gapsys-scale-linpoint-lj/q`, `sc-gapsys-sigma-lj`. **`sc-r`/`sc-n`/
  `sc-zero`/`sc-coulomb` are gone.**
- `dhdl-derivatives` is now **yes/no** (which ∂H/∂λ terms are written to the
  `.edr` for `gmx bar` / `gmx wham`).
- `init-lambda-state` selects the starting window index (replaces the old
  `init-lambda` float in multi-window setups).
