# 00.1 — Versions, Install, Environment Variables

## Version context

| Series | Status | Notes |
|--------|--------|-------|
| **2026.x** | **Current stable** | This stack builds **2026.3** (HIP, gfx1100). Target of this spec. |
| 2027 | In development | Do not target; APIs/defaults may shift. |
| ≤ 2025 | Legacy | Older tutorials may assume Berendsen etc. — see change notes below. |

Check the running version and build:

```bash
gmx --version            # series, patch, SIMD, GPU backend, FFT library
gmx grompp --version     # must match mdrun version for a .tpr
gmx check -s1 run.tpr    # sanity-check a run input file (note: -s1, not -s)
```

**A `.tpr` is version-specific**: `grompp` and `mdrun` must be the same GROMACS
version. Mixing versions corrupts the run.

## What's new in the 2026 series (agent-relevant)

- **Force fields**: AMBER14SB and AMBER19SB added (`pdb2gmx -ff amber14sb` /
  `amber19sb`). These ports are **validation pending** in the 2026 series —
  verify against the reference before relying on them.
- **Water models**: OPC and OPC3 added (recommended partners for the new
  AMBER protein FFs).
- **NNPot module**: neural-network / ML potentials, incl. hybrid NNP/MM
  (mechanical and electrostatic embedding). Requires a LibTorch-enabled build
  — **not enabled in this stack's build** (`Torch support: disabled`). See
  `02.11`.
- **H5MD trajectory output**: experimental, opt-in via `mdrun` trajectory type
  `h5md`. Not for production yet.
- **Full HIP support** (AMD GPUs). On this stack (gfx1100 / RX 7900 XTX):
  - Build uses `GMX_HIP_TARGET_ARCH=gfx1100` (GROMACS's own cache variable —
    the standard `CMAKE_HIP_ARCHITECTURES` is silently ignored).
  - GPU FFT defaults to **VkFFT** on consumer RDNA (rocFFT doesn't officially
    support them).
  - **GPU-resident update** (`-update gpu`) requires `-ntmpi 1` + a dynamical
    integrator; incompatible with FEP, domain decomposition, replica exchange.
    `constraints = h-bonds` is **performance-recommended** (avoids all-bonds
    P-LINCS communication overhead), not a hard requirement.
- **Experimental features** (env-var / build-flag gated, **not** for
  production): CUDA graphs (`GMX_CUDA_GRAPH`), H5MD output, NVSHMEM,
  multi-GPU parallel PME on HIP, direct halo communication
  (`GMX_FILLERS_IN_LOCAL_STATE`), NBNxM 1x1 kernels (`GMX_NBNXN_PLAINC_1X1`),
  VkFFT/oneMath/BBFFT FFT backends.

## Feature lifecycle (validation)

GROMACS labels features:
- **Experimental** — insufficiently tested; activate via env var / cmake flag;
  not for production.
- **Validation pending** — under validation; use with caution.
- **Stable** — default, validated.

Prefer stable features for anything that must be reproducible.

## Environment variables (operational)

| Variable | Purpose |
|----------|---------|
| `GMX_MAXBACKUP` | Max backup copies of output files (default 99). `0` = fail if output exists; `-1` = overwrite without backup. |
| `GMX_LOG_BUFFER` | File I/O buffer size; `0` = unbuffered (debugging: files always current). |
| `GMX_SUPPRESS_DUMP` | Prevent dumping step files (e.g. pdb) during constraint failures / blowing up. |
| `GMX_TPI_DUMP` | Dump configurations whose interaction energy < value (test-particle insertion debugging). |
| `GMX_TRAJECTORY_IO_VERBOSITY` | Trajectory I/O debug output. |
| `PLUMED_KERNEL` | Path to `libPlumedKernel.so` for PLUMED (metadynamics/umbrella). |
| `LD_LIBRARY_PATH` | Must include the PLUMED/NNP library prefix when using those modules. |

## Install / build notes for this stack

- Source: `rocm/dev-ubuntu-24.04:7.14.1-full` base (needs `hipcc`/`amdclang++`).
- CMake: **default Makefiles generator** (not Ninja — incompatible with
  `-DGMX_BUILD_OWN_FFTW=ON`).
- `GMX_SIMD=AVX2_256` forced (AVX-512 auto-detect on Zen4 segfaults).
- Verify GPU codegen: `gmx --version | grep "HIP compiler flags"` must show
  `--offload-arch=gfx1100`.
- See `../README.md` (sibling) for the full build gotcha list and benchmark
  reference numbers.

## Quick validation of a fresh install

```bash
gmx --version
gmx grompp --h | head        # preprocessing present
gmx mdrun --h | head         # run present
gmx nonbonded-benchmark -size 1 -nt 1 -iter 100   # (optional) non-bonded kernel benchmark
# NOTE: old `gmx benchmark` is gone in 2026.3. The replacement is
# `gmx nonbonded-benchmark` which benchmarks Nbnxm non-bonded pair kernels
# (not a full CPU/GPU suite). Key flags: -o out.csv, -size N (3000*N atoms),
# -nt N (OpenMP threads), -simd auto/no/4xm/2xmm, -coulomb ewald/reaction-field,
# -iter N, -warmup N, -all (all 36 combinations).
```
