# 00.2 — Command Surface (`gmx <subcommand>`)

Grouped by role. Only the flags an expert agent actually reaches for are
listed; run `gmx <cmd> --help` for the full reference.

## Preprocessing / system build

| Command | Purpose | Key flags |
|---------|---------|-----------|
| `pdb2gmx` | Build topology + coords from PDB using a force field | `-f` in.pdb `-o` out.gro `-ff` forcefield `-water` model `-p` topol out `-i` posre.itp out `-n` index.ndx (Opt.) `-q` clean.pdb (Opt.) `-chainsep` (id_or_ter) `-merge` (no) `-[no]ss` interactive SS bridge selection (bool) `-[no]ter` `-[no]lys`/`-arg`/`-asp`/`-glu`/`-gln`/`-his` charge states `-angle` (135) `-dist` (0.3) `-[no]una` `-[no]ignh` ignore input H `-[no]missing` allow missing `-posrefc` (1000) `-vsite` (none) `-[no]heavyh` `-[no]deuterate` `-[no]cmap` (yes) `-[no]renum` `-rtpres` (auto). **No `-igb`/`-pbr`/`-bact`/`-cys`/`-membrane`/`-zero`/`-altloc` in 2026.3; `-ss` is a boolean; posre via `-i`.** |
| `editconf` | Edit/convert structure, set box | `-f` in `-o` out `-bt` box type (triclinic) `-box <x y z>` `-angles <a b c>` `-d` solute-box distance (0) `-[no]c` center in box `-center <x y z>` `-scale <x y z>` `-density` (1000) `-[no]pbc` apply PBC `-resnr` (-1) `-rvdw` (0.12) `-label` (A). **No `-ct`/`-if`/`-of`; `-d` is solute-box distance, density is `-density`.** |
| `solvate` | Solvate in water box | `-cp` solute structure (Opt.) `-cs` water box (library file; default `spc216.gro`) `-box <x y z>` triclinic/cubic box (`0 0 0` = auto cubic) `-radius` default van der Waals distance (0.105 nm) `-scale` scale factor to multiply van der Waals radii from the database (0.57) `-shell` outer shell thickness (default 0) `-maxsol` max number of waters (0 = unlimited) `-p` (write topology snippet) `-o` out. **No `-f`, no `-dodeca`, no `-boxx/-boxy/-boxz`, no `-r` in 2026.3.** |
| `genion` | Generate ions, neutralize | `-s` topol.tpr (required) `-n` index.ndx (Opt.) `-p` topol `-o` out `-np` number of positive ions `-pname` (NA) `-pq` charge (1) `-nn` number of negative ions `-nname` (CL) `-nq` charge (-1) `-rmin` min distance (0.6 nm) `-seed` (0) `-conc` M (overrides `-np`/`-nn`) `-[no]neutral` (no) `-[no]seed`. **No `-select`, no `-pdb` in 2026.3.** |
| `insert-molecules` | Insert extra molecules (solute, lipids) | `-f` solute structure (Opt.) `-ci` molecule to insert (required) `-ip` positions file (Opt.) `-n` index (Opt.) `-o` out `-replace <selection>` `-sf` provide selections from files `-selrpos` (atom) `-box <x y z>` `-nmol` number of molecules (0 = auto) `-conc` M `-try` attempts per molecule (default 10) `-seed` `-radius` (0.105) `-scale` (0.57) `-dr` `-rot` (xyz). **No `-maxattempt` in 2026.3.** |
| `make_ndx` | Build index groups | `-f` in `-n` index in (Opt.) `-o` index.ndx out `-natoms` (0) `-[no]twin`. **No `-select`/`-id` — group building is interactive.** |
| `select` | Atom selection (SELFLANG) | `-f` traj (Opt.) `-s` top (Opt.) `-n` index (Opt.) `-select <selection>` `-oi` index.dat (Opt.) `-on` index.ndx (Opt.) `-of` occupancy.xvg (Opt.) `-olt` lifetime.xvg (Opt.) `-resnr` (number) `-b`/`-e`/`-dt` times. **No `-index`/`-output`/`-res`.** |
| `mk_angndx` | Index file of angles/dihedrals | `-s` topol.tpr `-n` angle.ndx out `-type` (angle) `-[no]hyd` (yes) `-hq` (-1). **No `-f`/`-o`.** |
| `genrestr` | Generate position-restraint `.itp` | `-f` in `-n` index (Opt.) `-o` posre.itp out `-of` freeze.ndx (Opt.) `-fc` (1000 1000 1000) `-freeze` (0) `-[no]disre` `-cutoff` (-1) `-[no]constr`. **No `-group` — use `-n`.** |
| `grompp` | Pre-process `.top`+`.mdp`+coords → `.tpr` | `-f` mdp `-c` coords `-p` top `-r` restraint.gro `-rb` restraint2.gro `-n` index (Opt.) `-t` traj.trr (continuation, Opt.) `-e` ener.edr (Opt.) `-ref` rotref.trr (Opt.) `-po` mdout.mdp `-pp` processed.top (Opt.) `-o` out.tpr `-maxwarn` (use sparingly) `-time` (-1) `-[no]zero` `-[no]renum` (yes). **No `-i` — continuation input is `-t`.** |
| `convert-tpr` | Modify a `.tpr` (extend nsteps, etc.) | `-s` in `-n` index (Opt.) `-o` out `-extend` (0) `-until` (0) `-nsteps` (0) `-[no]generate_velocities` `-velocity_temp` (300) `-velocity_seed` (-1). **No `-define`.** |

## Run

| Command | Purpose | Key flags |
|---------|---------|-----------|
| `mdrun` | Run the simulation | `-deffnm` default file prefix `-s` tpr `-cpi` checkpoint in `-cpo` checkpoint out `-cpt` checkpoint interval (minutes, 15) `-rerun` rerun.xtc (Opt.) `-maxh` max wall hours `-ntmpi` thread-MPI ranks `-ntomp` OpenMP threads `-nt` total threads `-nb/-pme/-bonded/-update` gpu/cpu `-plumed` plumed.dat (Opt.) `-multidir` run a directory tree `-x` compressed traj (Opt.) `-o` traj.trr `-c` confout.gro `-e` ener.edr `-g` md.log `-dhdl` dhdl.xvg (Opt.) `-tpi`/`-tpid` TPI outputs (Opt.) `-[no]v` verbose. **No `-f` (use `-s`), no `-continue`/`-nocontinuation` (restart = `-cpi` alone), no `-colvars` (Colvars is MDP-only: `colvars-active`/`colvars-configfile`), no `-debug` in 2026.3.** |
| `check` | Check and compare files (tpr/cpt/trajectories) | `-f`/`-f2` trajectory (Opt.) `-s1`/`-s2` top1.tpr (Opt.) `-n` index.ndx (Opt.). **No `-s` flag in 2026.3 — use `-s1`/`-s2`.** |
| `dump` | Dump binary (tpr/cpt/edr) as text | `-s` topol.tpr (Opt.) `-f` trajectory (Opt.) `-cp` state.cpt `-om` mdp (Opt.) |

## Trajectory processing

| Command | Purpose | Key flags |
|---------|---------|-----------|
| `trjconv` | Convert/fix trajectory (PBC, fit, center) | `-s` top (Opt.) `-f` in `-o` out `-n` index (Opt.) `-pbc` none/mol/res/atom/nojump/cluster/whole `-fit` none/rot+trans/rotxy+transxy/translation/transxy/progressive `-[no]center` `-dt` `-b`/`-e` time range `-skip` (1) `-ur` (rect) `-boxcenter` (tric) `-trans <x y z>` `-shift <x y z>`. **No `-surround`/`-resnum`/`-fitref`/`-compress`; use `-b`/`-e` (not `-begin`/`-end`).** |
| `trjcat` | Concatenate trajectories, apply shift | `-f` (multiple) `-o` out `-n` index (Opt.) `-demux` remd.xvg (Opt.) `-b`/`-e` time range `-dt` (0) `-[no]settime` `-[no]sort` (yes) `-[no]keeplast` `-[no]overwrite` `-[no]cat`. **No `-skip`/`-shift`/`-set-switch`/`-single`.** |
| `convert-trj` | Convert between trajectory types (replaces old `trjpos`) | `-s` `-f` in `-o` out `-vel` |
| `xpm2ps` | Render `.xpm` image to PostScript | `-f` in.xpm `-o` out.ps |

**Removed in 2026.3** (no replacement or see above): `trjpos` (→ `convert-trj`), `xvdgen`, `mktube`, `charge`, `ion2group`, `pmx`, `fit`, `nmat`, `pmat`, `dipole` (→ `dipoles`), `rotinv`, `axias`, `solvation`, `g_wham` (→ `wham`), `benchmark` (→ `nonbonded-benchmark`), `insert` (→ `insert-molecules`), `sander`, `do_rms`, `do_wham`, `analysis`.

|---------|----------|
| `energy` | energies, pressure, density, box volume, COM velocity |
| `analyze` | generic time-series analysis of any `.xvg`/`.dat` (correlation, block averaging, integration) |
| `rms` / `rmsf` | RMSD / RMSF (flexibility) |

| `rdf` | radial distribution function |
| `msd` | mean-square displacement → diffusion coefficient |
| `angle` / `gangle` | angles / generalized angles |
| `distance` / `pairdist` / `mindist` | distances (time series, distribution, min) |
| `dssp` | secondary structure (per frame) |

| `covar` / `anaeig` | covariance / PCA (essential dynamics) |

## Notes

- Every analysis tool reads **index groups** (`-n`); build them with
  `make_ndx`/`select` (see `01.8`).
- **`do_*` aliases are gone in 2026.3** — `gmx do_rms`, `gmx do_wham`, etc. no
  longer exist. Use the canonical command names (`gmx rms`, `gmx wham`).
- **`gmx -maxwarn N` on `grompp` silently ignores unknown/deprecated MDP
  options** — it downgrades "Unknown left-hand" errors to warnings and the
  resulting `.tpr` will run with the *default* value for that option, not the
  one you wrote. If you need `-maxwarn` for a legitimate warning, verify the
  option actually took effect by checking the `grompp` log or the `.tpr`.
- Units: nm, ps, K, bar, kJ/mol, kJ/mol/nm, kJ/mol/nm², amu.
