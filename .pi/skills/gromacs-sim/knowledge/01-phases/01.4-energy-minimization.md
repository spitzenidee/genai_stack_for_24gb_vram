# 01.4 — Phase 4: Energy Minimization

**Purpose**: remove steric clashes and relax the system to a local energy
minimum before any dynamics. A bad EM poisons every later phase.

## Inputs
- `solvated_ions.gro` + `.top` from Phase 3.
- `em.mdp`.

## Steps

1. **Write `em.mdp`** (see template `03.2`):
   ```
   integrator  = steep
   nsteps      = 50000
   emtol       = 10
   emstep      = 0.01
   ```
2. **Preprocess**:
   ```bash
   gmx grompp -f em.mdp -c solvated_ions.gro -p topol.top -r solvated_ions.gro \
       -o em.tpr
   ```
   `-r` takes a **structure file** (`.gro`/`.pdb`) of restraint reference
   coordinates — never a `.itp`. It is **mandatory** when position restraints
   are active; here the starting structure serves as its own reference.
3. **Run**:
   ```bash
   gmx mdrun -deffnm em
   ```
4. **Inspect** `em.log` + `em.gro`:
   - **`Fmax`** (max force) is the key metric — must be `< emtol`.
   - `Epot` for a solvated system is typically ~ **-10⁵ to -10⁶ kJ/mol**.
   - No LINCS/SHAKE warnings.

## Integrators (EM)

| `integrator` | Notes |
|--------------|-------|
| `steep` (steepest descent, default) | Robust; fine for most EM. |
| `cg` (conjugate gradient) | Faster near the minimum; **constraints are allowed** (the old "Can not do Conjugate Gradients with constraints" check is gone in 2026.3). Used before normal-mode analysis. |
| `l-bfgs` | Quasi-Newton; good for larger systems. |

## Key MDP options

| Option | Recommended | Rationale |
|--------|-------------|-----------|
| `integrator` | `steep` | Robust default. |
| `emtol` | `10` kJ/mol/nm | Sufficient for starting MD. Use **1e-4 or lower** only for normal-mode analysis. |
| `emstep` | `0.01` nm | Initial step. |
| `nsteps` | 50000–100000 | Cap; EM usually converges well before. |
| `constraints` | `none` for EM (or h-bonds) | `cg` may use constraints (no longer rejected in 2026.3). |

## Interpreting results

- **`Fmax < emtol`** → converged; proceed.
- **`converged to within the available machine precision`** → *not* an error; the system is at a practical minimum. For a
  solvated system with `Fmax` between 10 and 1000 kJ/mol/nm and `Epot` ~
  -10⁵…-10⁶, this is a fine starting point.
- **`force on at least one atom is not finite`** → two atoms too close
  (steric clash / bad starting structure). Fix the structure, re-minimize, or
  (for CG systems like Martini) use **soft-core** equilibration.
- **Double precision** GROMACS can push a difficult EM further if needed.

## Common errors (→ `01.9`)
- `Can not do Conjugate Gradients with constraints` — no longer emitted (gone in 2026.3; `cg` + constraints is accepted).
- `force ... not finite` — clashes (see above).
- `The cut-off length is longer than half the shortest box vector` — box too
  small (Phase 3).

## Validation criteria (gate to Phase 5)
- [ ] `Fmax < emtol` (or machine-precision message with sane `Epot`/`Fmax`).
- [ ] No constraint warnings in `em.log`.
- [ ] `em.gro` visually sane (no exploded regions).

## Outputs
`em.tpr`, `em.gro` (minimized structure), `em.edr`, `em.log`. Use `em.gro` as
the starting structure for equilibration.
