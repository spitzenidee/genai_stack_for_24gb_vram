# 01.3 — Phase 3: Solvation, Ions & Box

**Purpose**: place the system in a solvent box of correct size, add ions for
neutralization + physiological salt, and update the topology.

## Inputs
- `protein.gro` (+ ligand coords) and `.top` from Phase 2.
- Water model + ion set matched to the FF (`00.6`).

## Steps

1. **Solvate**:
   ```bash
   gmx solvate -cp protein.gro -cs spc216.gro -o solvated.gro -p topol.top \
       -radius 1.0
   ```
   - `-cp` = solute structure (the old `-f` flag is gone).
   - `-cs` = water **box file** (default `$GMXLIB/spc216.gro`); the SPC
     coordinates also serve any 3-site model (SPC/E, TIP3P, OPC, OPC3) — the
     actual model is set by the topology include (see `00.6`). For 4-site
     waters use a 4-site box (e.g. `$GMXLIB/tip4p.gro`). **No `-dodeca`, no
     `-boxx/-boxy/-boxz`** in 2026.3; use `-box <x y z>` for a custom box.
   - `-radius` = min distance from solute to box wall (**default 0.105 nm** —
     explicitly set ≥ 1.0 nm, and ≥ your cutoff).
   - `-p` writes the topology snippet (SOL count) to append to `[ molecules ]`.
2. **Box-size rule (minimum image)**:
   - The **cutoff** (`rvdw`/`rcoulomb`, and `rlist`) must be **< half the
     shortest box vector** in every dimension.
   - Practically: box ≥ **2 × cutoff** in all dimensions. With a 1.0–1.2 nm
     cutoff, keep the smallest box dimension ≥ ~2.4–2.6 nm from the solute
     surface.
   - If using **pressure coupling**, the box shrinks/grows — leave margin so it
     never dips below the cutoff rule during the run.
3. **Generate ions** (2026.3 workflow — `-s` now requires a `.tpr`):
   ```bash
   gmx grompp -f ionize.mdp -c solvated.gro -p topol.top -o solvated.tpr
   gmx genion -s solvated.tpr -p topol.top \
       -o solvated_ions.gro -neutral -conc 0.15
   ```
   - `-s` takes a **`.tpr` only** (not a `.gro`); build one with a trivial MDP
     (`integrator = steep`, `nsteps = 0`).
   - `-neutral`: add counter-ions to zero the net charge.
   - `-conc 0.15`: ~physiological salt after neutralization.
   - Ions replace waters (default group `SOL`); **`-select` is gone**.
   - genion **updates `topol.top`** (appends `SOL`, `NA`, `CL` counts to
     `[ molecules ]`).
   - Fine control: `-np/-pname/-pq`, `-nn/-nname/-nq`, `-rmin` (0.6 nm),
     `-seed`.
4. **Insert extra solutes** (optional):
   ```bash
   gmx insert-molecules -f solvated_ions.gro -ci extra.gro \
       -o final.gro -nmol 50 -try 25000
   ```
   - `-f` = existing system structure, `-ci` = molecule to insert (required),
     `-nmol` count (0 = auto from `-conc`), `-try` attempts per molecule
     (default 10; **`-maxattempt` is gone**). `-box <x y z>` generates a fresh
     box instead of inserting into `-f`.
5. **Check the final system**:
   - Net charge ≈ 0 (integer).
   - Water/ion counts sensible; no ions overlapping the solute (genion avoids
     clashes, but verify).

## Key MDP-relevant facts
- Box type affects `pcoupltype` choice (membranes → `semiisotropic`, see
  `02.13`).
- Cutoffs set here must be consistent with the MDP (`rvdw`, `rcoulomb`,
  `rlist`).

## Common errors (→ `01.9`)
- `The cut-off length is longer than half the shortest box vector ...` — box
  too small for the cutoff (or `rlist` too large). Enlarge box or reduce
  cutoff.
- Ions inside the protein (bad `-select` or too-small box).
- Non-integer total charge after genion (topology bug upstream).

## Validation criteria (gate to Phase 4)
- [ ] Box ≥ 2 × cutoff in all dimensions (with margin for NPT).
- [ ] Net charge ≈ 0 (integer).
- [ ] Ion concentration as intended; no solute–ion clashes.
- [ ] Topology `[ molecules ]` updated and order-consistent.

## Outputs
`solvated_ions.gro`, updated `.top`, and documented box dimensions + ion
counts.
