# 01.5 — Phase 5: Equilibration (NVT → NPT)

**Purpose**: bring the system to the target temperature and pressure, relax the
box, and let the solvent organize — while the solute is held by position
restraints. Two sub-stages: **NVT** (temperature), then **NPT** (pressure +
box).

## Inputs
- `em.gro` (minimized) + `.top` + posre file.
- `nvt.mdp`, `npt.mdp`.

## Stage A — NVT (constant T, fixed box)

1. **`nvt.mdp`** (see template `03.2`):
   ```
   integrator  = md
   nsteps      = 50000          ; 100 ps at 2 fs
   dt          = 0.002
   tcoupl      = v-rescale
   tau-t       = 0.1 0.1
   ref-t       = 300 300
   tc-grps     = Protein Non-Protein
   pcoupl      = no
   constraints = h-bonds
   gen-vel     = yes            ; only for the very first run
   gen-temp    = 300
   gen-seed    = 42
   ```
2. **Preprocess + run** (with posre on the solute; `-r` = reference coords):
   ```bash
   gmx grompp -f nvt.mdp -c em.gro -p topol.top -r em.gro -o nvt.tpr
   gmx mdrun -deffnm nvt
   ```
3. **Typical length**: 0.1–0.5 ns. Watch that temperature reaches ~300 K and
   kinetic energy stabilizes.

### Thermostat choice (2026)

| `tcoupl` | Ensemble | Use |
|----------|----------|-----|
| **`V-rescale`** | Correct canonical (NVT) | **Recommended** for equilibration + production. Works even at `tau-t=0`. |
| `Nose-Hoover` | Correct NVT | Use with `integrator = md-vv`. |
| `Andersen` / `Andersen-massive` | Approximate | Velocity randomization; **not supported with `integrator = md`** (error: "Andersen temperature control not supported for integrator md"); use with `sd`/`bd` and set `nstcomm = 1`. |
| `Berendsen` | **Incorrect** ensemble | **Discouraged for new production** (fine for quick equilibration). |

- Full enum (2026.3, case-insensitive): `No`, `Berendsen`, `Nose-Hoover`,
  `yes`, `Andersen`, `Andersen-massive`, `V-rescale`.
- `tau-t = 0.1 ps` (0.05–0.2 typical). `tc-grps`: couple protein and
  non-protein **separately** (different relaxation). **Never** couple a tiny
  group to its own bath — `grompp` no longer errors (the old "fewer than 10%
  of the atoms" check is gone); it only prints the degrees-of-freedom NOTE.
  Merge small groups.

## Stage B — NPT (constant T + P, box relaxes)

1. **`npt.mdp`** (see template `03.2`):
   ```
   integrator  = md
   nsteps      = 250000         ; 500 ps at 2 fs
   dt          = 0.002
   tcoupl      = v-rescale
   tau-t       = 0.1 0.1
   ref-t       = 300 300
   tc-grps     = Protein Non-Protein
   pcoupl      = C-rescale
   pcoupltype  = isotropic
   tau-p       = 2.0
   compressibility = 4.5e-5     ; water at 1 atm, 300 K
   ref-p       = 1.0
   refcoord-scaling = com       ; scale posre reference coords with the box
   constraints = h-bonds
   ```
2. **Preprocess + run** (continue from NVT, **keep posre**; `-r` = reference
   coords, a structure file — not the `.itp`):
   ```bash
   gmx grompp -f npt.mdp -c nvt.gro -p topol.top -r em.gro -o npt.tpr
   gmx mdrun -deffnm npt
   ```
3. **Typical length**: 0.5–2 ns (longer for membranes/large systems). Watch
   pressure → ~1 bar, box volume stabilize, density correct.

### Barostat choice (2026)

| `pcoupl` | Ensemble | Use |
|----------|----------|-----|
| **`C-rescale`** | Correct NPT | **Recommended** for equilibration + production. |
| `Parrinello-Rahman` | Correct NPT | Production; **can oscillate** if starting far from equilibrium. |
| `MTTK` | Correct NPT | **Deprecated** (use C-rescale / PR); **requires Nose-Hoover temperature control (`tcoupl = nose-hoover`), which needs `integrator = md-vv`; constraints allowed**. |
| `Isotropic` | **Incorrect** (legacy Berendsen) | **Legacy alias for `Berendsen`** — grompp rewrites it to `Berendsen` (wrong ensemble, discouraged). It does pair with `pcoupltype`, but use `C-rescale`/`Parrinello-Rahman` instead. |
| `Berendsen` | **Incorrect** ensemble | **Discouraged for new production** (ok to relax volume early). |

- Full enum (2026.3, case-insensitive): `No`, `Berendsen`, `Parrinello-Rahman`,
  `Isotropic`, `MTTK`, `C-rescale`.

- `tau-p = 2.0 ps` (2–5 typical). Too-small `tau-p` + not-yet-equilibrated
  system → **box oscillation → `Pressure scaling more than 1%` crash**.
- `compressibility = 4.5e-5 bar⁻¹` (water). 
- `refcoord-scaling = com` (or `all`) **required** when using position
  restraints in NPT (otherwise restraints fight the box scaling). Note: `yes`
  is **not** a valid value (enum: `no`/`com`/`all`).
- `pcoupltype`:
  - `isotropic` — default (bulk solution).
  - `semiisotropic` — **membranes** (couple x/y and z separately; needs 2
    compressibility + 2 ref-p values). See `02.13`.
  - `anisotropic` / `surface-tension` — specialized.

### NPT convergence: pressure and density

- **Pressure is a wildly fluctuating microscopic quantity** — instantaneous
  values vary a lot, and the average need not match `ref-p` exactly. An NPT
  average of e.g. **−3 ± 11 bar vs. target 1 bar** is statistically
  indistinguishable from target (the target lies inside the error bar); **do
  not extend equilibration to chase the exact value**.
- **Density is the more robust NPT-convergence indicator** (less noisy than
  pressure). A solvated-protein density slightly above pure water (repo:
  **1025 ± 0.5 vs. 986 kg/m³** for TIP3P) is expected — the system contains
  protein + ions, so it will not equal bulk water exactly. A **constant
  density** over the NPT phase ⇒ adequately equilibrated.
- **NPT length**: for a solvated protein in a dodecahedron box at 310 K,
  500 ps NPT is often insufficient for pressure equilibration (repo: lysozym
  310 K — 500 ps failed the pressure gate, 1000 ps passed; a 300 K run needed
  4000 ps). **Plan for 1000 ps minimum.**

## COM motion
- Remove center-of-mass motion with **`nstcomm`** (frequency) plus
  **`comm-mode`** (what to remove). There is **no** `constr-com` option.
  For production-quality data remove translation (+rotation for non-isotropic
  systems):
  ```
  nstcomm     = 1000
  comm-mode   = Linear            ; or 'Angular' to also remove rotation
  ```

## Staged restraint relaxation (optional, for sensitive systems)
- Run NPT in steps with **decreasing** posre force constants (e.g. 1000 → 250
  → 50 kJ/mol/nm²), re-grompp between steps. See `02.02`.

## Common errors (→ `01.9`)
- `Pressure scaling more than 1%` — box oscillation: insufficient
  equilibration, `tau-p` too small, or PR on an unequilibrated system (use
  C-rescale).
- `Number of degrees of freedom in T-Coupling group X is N` (NOTE; the old "fewer than 10% of the atoms" error is gone in 2026.3) — merge small groups.
- `The cut-off length is longer than half the shortest box vector` — box
  shrunk below cutoff rule under pressure; enlarge box / reduce cutoff.
- LINCS/SHAKE warnings early — clashes or too-large `dt`; re-minimize, reduce
  `dt`.

## Validation criteria (gate to Phase 6)
- [ ] Temperature stable at `ref-t` (± a few K).
- [ ] Pressure stable near `ref-p`; box volume/density stable.
- [ ] No constraint warnings; energy terms not spiking.
- [ ] Solute RMSD stable (restraints working).
- [ ] Density of water ≈ expected for the model (e.g. SPC/E ~0.99 g/cm³).

## Outputs
`nvt.tpr/.gro/.edr/.log`, `npt.tpr/.gro/.edr/.log`. Use `npt.gro` (or the end
of the NPT trajectory) as the production start; **drop position restraints**
for production unless the protocol requires them.
