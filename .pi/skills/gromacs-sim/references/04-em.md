# Phase 4 — Energy minimization

Entry: `03_solvation/` passed its gate. Work in `<sim>/04_em/`.

## Steps

CPU by default (transient container, any mode). **GPU-EM is Tier B** — only
when the system is large (≳100k atoms) or EM is part of a batch/iterative
loop; for typical protein/ligand sizes (<100k atoms) CPU EM takes minutes and
the mode-switch ceremony isn't worth it. Record the choice in `RUNLOG.md`.

```bash
# copy inputs into the phase dir first (host):
cp <sim>/03_solvation/{ions.gro,topol.top} <sim>/04_em/
# render assets/em.mdp (and cg.mdp for the fallback) into 04_em/

# guard: no duplicate/orphan mdrun (hard rule 2)
bash .pi/skills/gromacs-sim/scripts/check_running.sh <sim>
# SD
docker run --rm -w /work/projects/<sim>/04_em -v "$PWD/gromacs/work":/work \
  gromacs-hip-gfx1100:latest bash -c '
    set -e
    cd /work/projects/<sim>/04_em
    gmx grompp -f em.mdp -c ions.gro -p topol.top -o em.tpr
    gmx mdrun -deffnm em
  '
```

## CG fallback (D10)

**Gate first (never skip a gate — SKILL.md):** run `check_em.sh` on the SD
output and only
fall back to CG if it FAILS. A machine-precision SD (Fmax 10..1000,
"converged to within the available machine precision") PASSES the gate per
KB 01.4 — do not second-guess the gate and "improve" a passing EM with CG
(issues_agent_run: lysozym ran an unnecessary CG after a passing SD).

If the gate fails because SD did not converge within `nsteps` (log: no
"converged" line, Fmax ≥ emtol): run CG **from SD's final structure**:

```bash
gmx grompp -f cg.mdp -c em.gro -p topol.top -o em_cg.tpr
gmx mdrun -deffnm em_cg
```

Record `gates.em.algo = "cg"` and `files.em_out = 04_em/em_cg.gro` in
`state.json`.

## GPU-EM (Tier B — large systems / batch only)

Uses **`-nb gpu` only** — `steep`/`cg` are non-dynamical integrators, so
`-pme gpu`/`-bonded gpu`/`-update gpu` are rejected (KB `03.5`). Live
container, gromacs mode (run `preflight.sh <sim> --gpu` first):

```bash
docker compose exec -w /work/projects/<sim>/04_em gromacs-rocm bash -c '
  set -e
  cd /work/projects/<sim>/04_em
  gmx grompp -f em.mdp -c ions.gro -p topol.top -o em.tpr
  gmx mdrun -deffnm em -ntmpi 1 -nb gpu
'
```

The phase-5/6 GPU ladder (SKILL.md) does **not** apply to EM — `-nb gpu` is
the only GPU task allowed for a non-dynamical integrator.

## Gate

```bash
scripts/check_em.sh <sim_dir>
```

Checks: final Fmax < emtol (SD or CG log, whichever ran), Epot in the
solvated-biomolecule band (−10⁶…−10⁴ kJ/mol, KB 01.4), no LINCS/SHAKE/
exceeded/Panic lines.

KB: `01.4` (EM). "converged to within the available machine precision" is
**not** an error. Failure modes: `01.9`.
